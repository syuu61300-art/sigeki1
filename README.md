# 紙撃（しげき）

**折り紙の式神を、墨で撃て。**

金屏風の間から月夜の枯山水、紅葉の山寺、そして魔王城へ。折り紙の式神を墨で撃ち抜いて進む一人用のFPSです。
ブラウザだけで動き、PC（マウスとキーボード）とスマホ（タッチ操作）の両方で遊べます。

## 遊び方

### PC

「出陣」をクリックするとマウスが画面に固定されます。

| 操作 | キー |
|---|---|
| 移動 | W A S D（矢印キーでも可） |
| 視点 | マウス |
| 射撃 | 左クリック（押しっぱなしで連射） |
| 構え（ズーム） | 右クリック |
| ジャンプ | Space |
| 回避（短い無敵ダッシュ） | Shift |
| 墨継ぎ（リロード） | R |
| 武器の持ち替え | 1・2・3、マウスホイール |
| 奥義「一文字」 | Q |
| 一時停止 | Esc |

### スマホ

横向きがおすすめです。

| 操作 | やり方 |
|---|---|
| 移動 | 画面の左側に指を置くと、その場所がスティックになります |
| 視点 | 画面の右側をドラッグ |

照準が敵に重なると自動で撃つ「自動射撃」が、スマホでは最初からオンになっています。設定で切り替えられます。

## ルール

- 陣（ウェーブ）ごとに現れる式神をすべて倒すと、次の陣へ進みます。
- 陣を破るたびに、強化の短冊を3枚から1枚選べます（26種類。すべて取り切ると、何度でも取れる「墨力」「養生」「練達」が出ます）。
- 取った強化は倒れても消えず、次の出陣でもそのまま使えます（設定の「強化を引き継ぐ」で切り替え、「強化を初期化」でやり直せます）。
- 武器は3種類です。第二陣から「散墨」、第四陣から「硯砲」が使えます。
  - **墨弾**：連射できる筆。
  - **散墨**：近距離で強い竹筒。
  - **硯砲**：着弾すると墨が爆ぜて、周りの敵をまとめて倒せます。
- 五陣ごとに大将が現れます。大将の顔ぶれは十陣ごとに変わり、第百陣の大将は「魔王」です。
- 十一陣ごとに新しい式神が加わり、陣が進むほど敵は硬く、速く、数も増えます。
- 三十陣ごとに新しい戦場へ進みます。

| 戦場 | 陣 |
|---|---|
| 金屏風の間 | 第一〜三十陣 |
| 月夜の枯山水 | 第三十一〜六十陣 |
| 紅葉の山寺 | 第六十一〜九十陣 |
| 魔王城 | 第九十一陣〜 |

![四つの戦場](images/stages.jpg)

- 十陣を破るごとに区切りが記録されます。タイトル画面に「第十一陣から」のボタンが現れ、破ったときの強化と得点を引き継いで続きから挑めます（「‹」「›」で前の区切りも選べます）。倒れたときの画面からも、直前の区切りから挑み直せます。まだ破っていない区切りからは始められません。
- 奥義「一文字」：画面を横切る一筆で、前方の敵をまとめてなぎ払います。中央の硯の「海」（黒く光る部分）に立つと早く溜まります。
- 命は、しばらく攻撃を受けなければ回復します。敵が落とす御守りを拾っても回復します。

### 得点

- 頭などの弱点に当てると「会心」で二倍のダメージになります。
- 素早く倒し続けると「連撃」の倍率が上がります（最大5倍）。
- 「一石二鳥」「一網打尽」「返り討ち」「誘爆」「見切り」「無傷」などのボーナスがあります。
- 最高得点・最高到達の陣・記録した区切りは、遊んだブラウザに保存されます。

## オンラインマッチ（2〜4人の協力プレイ）

タイトルの「オンラインマッチ」から、仲間と同じ陣に挑めます。

1. 一人が「サーバーを作る」で、サーバー名・パスワードの有り無し・人数を決めて作ります。
2. ほかの人は「サーバーに入る」で、同じサーバー名（とパスワード）を入れて入ります。
3. そろったら、作った人が「出陣」を押します。

- 敵・陣・得点は全員で共通です。強化の短冊はそれぞれが選びます。
- 仲間の姿は透明で、輪郭と持っている銃と名札（名前と命のゲージ）だけが見えます。
- 倒れても、誰かが陣を破れば復活します。全員が倒れると終わりです。
- オンライン中は一時停止できません（メニューを開いても戦いは続きます）。
- **GitHub Pages で遊ぶとき**は、WebRTC で端末どうしを直接つなぎます。サーバー名を相手に伝えて入ってもらってください。つなぎ方は5通りあり、オンラインマッチ画面の「接続方法」で選べます。

| 接続方法 | しくみ |
|---|---|
| 自動（おすすめ） | ホストは下の5つ全部で同時に待ち、入る側は全部を同時に試します。つながった方法はすべて使い続け、いちばん早く届いたデータを採用するので、最初は MQTT中継で入っても、直接つながる方法が開いた時点で自動的にそちらが主になります |
| MQTT中継 | HiveMQ・EMQX・Mosquitto・Eclipse・shiftr.io・FreeMQTT・MQTTHQ・Bevywise など15か所の公開 MQTT ブローカーを同時に使い、データを中継してもらいます。端末どうしを直接つながない（WebRTC を使わない）ので、直接つながらないネットワークでも遊べます |
| PeerJS | PeerJS の公開サーバーで相手を探し、直接つなぎます |
| Nostr | Nostr のリレーで相手を探し、直接つなぎます |
| トレント | WebTorrent のトラッカーで相手を探し、直接つなぎます |
| MQTT（P2P） | 公開の MQTT ブローカーで相手を探し、直接つなぎます |

  どれか1つが止まっていても、ほかの方法でつながります。
- **通信の速さ**：入った側の画面左上に「通信 120ms・PeerJS」のように、往復にかかる時間と今使っている方法が出ます（250ms を超えると赤）。MQTT中継は海外のサーバーを経由するので遅めです。遅いときは「自動」にすると、直接つながる方法が使えれば自動で切り替わります。
  - 状態は1秒に20回やりとりし、敵や仲間は届いた位置と速さから「今いるはずの場所」を予測して描くので、遅れがあってもカクつきにくくなっています。
  - 自分の攻撃はすぐ画面に反映され、倒しきった敵はその場で倒れます（ホストの判定が違った場合だけ戻ります）。画面の下に、それぞれの方法の状態（待機中・接続・見つからない）が出ます。学校や会社のネットワークでは、どの方法でもつながらないことがあります。
- **claude.ai で遊ぶとき**は、このページを開いている人どうしでつながり、開いているサーバーが一覧に出ます。友だちと遊ぶには、ページを共有してください。

## フレンドと名前

- はじめて開いたときに名前を決めます（設定でいつでも変えられます）。
- 設定とフレンド画面に、名前・ID・最高到達・はじめた日・称号の5行の「プレイヤー情報」が自動で作られます。
- 相手のプレイヤー情報をフレンド画面に貼り付けると、フレンドになります。claude.ai では、フレンドがオンラインか、サーバーで待っているかが分かり、「参加」で入れます。

## 記録と引き継ぎ

- 記録（最高得点、区切り、強化、設定、ボタン配置、キー設定）は自動で保存されます。ページを更新しても消えません。
- 遊んでいる途中でページを閉じたり更新したりしても、タイトルの「続きから」でその陣の始めから再開できます。
- claude.ai で遊んでいるときは、記録が自分のアカウントにも保存されるので、同じアカウントなら別の端末でも続きから遊べます。
- GitHub Pages など claude.ai の外で遊ぶときは、記録はそのブラウザに保存されます。別の端末へ移すときは、設定の「引き継ぎコードを作る」で出た文字列を、移したい端末の「引き継ぎコードを入れる」に貼り付けてください。

## 操作の変更

- 設定の「ボタン配置を変える」で、スマホのボタンを指で動かして好きな位置と大きさにできます。
- 設定の「キー設定」で、PC のキーを変えられます。
- 遊び方の画面には、今のボタン配置とキーがそのまま表示されます。

## 見た目とマップ

- 設定の「画質」で 低・中・高 を選べます。「詳細設定」では、解像度・描画距離・エフェクトの量・光のにじみ・輪郭線の濃さ・テクスチャ・墨絵の仕上げ・足元の影・アンチエイリアスを自分で調整できます（動かすと「カスタム」になります）。
- 「墨絵の仕上げ」は、輪郭線、紙の質感、光のにじみを加えるシェーダーです。
- 右上のマップには、戦場の見取り図（柱や岩などの障害物、硯の海）、敵（地上は丸、空中は三角、大将は赤い輪、攻撃中は点滅）、仲間、御守り、手裏剣、衝撃波が表示されます。設定で表示のオン・オフ、大きさ、範囲、北を上に固定するかを変えられます。
- オンラインで倒れると、仲間の肩越しの観戦カメラになります（クリック・タップで観戦する仲間を切り替え）。
- 倒れたあとの画面からは「もう一度」「ロビーに戻る」「タイトルへ」を選べます。オンラインでは、ホストの「もう一度」で同じ仲間と続けて遊べます。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作ります（例：`shigeki`）。公開範囲は **Public** にします。
2. リポジトリの画面で **Add file** → **Upload files** を開き、このフォルダの中身をすべてドラッグ＆ドロップして **Commit changes** を押します。
3. **Settings** → 左のメニューの **Pages** を開きます。
4. **Build and deployment** の **Source** で **Deploy from a branch** を選び、ブランチを **main**、フォルダを **/(root)** にして **Save** を押します。
5. 少し待つと `https://ユーザー名.github.io/リポジトリ名/` で遊べるようになります。進み具合はリポジトリの **Actions** タブで確認できます。

GitHub Free では、Pages を使えるのは Public のリポジトリだけです。

## 動作環境

- WebGL が使える最近のブラウザ（Chrome、Edge、Safari、Firefox）
- three.js とフォントをCDNから読み込むため、インターネット接続が必要です
- 動きが重いときは、設定の「画質」を「低」にしてください

## 使用しているもの

- [three.js](https://github.com/mrdoob/three.js) r128（MIT License）を cdnjs から読み込んでいます
- オンラインマッチ用に `net/` フォルダの次のライブラリを使っています（どれも MIT License）：[PeerJS](https://github.com/peers/peerjs) 1.5.4、[Trystero](https://github.com/dmotz/trystero) 0.25.4（Nostr・トレント・MQTT）とその依存ライブラリ（[@noble/secp256k1](https://github.com/paulmillr/noble-secp256k1)、[MQTT.js](https://github.com/mqttjs/MQTT.js) ほか）
- フォント [Yuji Boku](https://github.com/Kinutafontfactory/Yuji) と [Zen Kaku Gothic New](https://github.com/googlefonts/zen-kakugothic)（SIL Open Font License 1.1）を Google Fonts から読み込んでいます
- 効果音と音楽はすべてプログラムで合成しています。テクスチャも実行時に描いているので、画像や音声のファイルは使っていません
